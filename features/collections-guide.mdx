title: "Collections"

---

A collection defines a type of content and belongs to a project. Create a separate collection for each content type you want to manage, such as blog posts, products, case studies, authors, or categories.

## Plan a collection

Before creating fields, list the information that belongs to each item. A blog post collection, for example, could contain a title, body, hero image, publication date, and category. Keep each collection focused on one kind of record.

## Collection identity

Each collection has a name, a URL-friendly slug, a project, an owner, and an `updatedAt` timestamp. Betacms indexes collections by project and slug so collections can be looked up within a project.

## Add fields

Fields define the shape of collection items. A field has a name, key, type, required setting, position, and owner. Fields can also include a description. Option fields can store a list of option IDs and labels, and reference fields can point to another collection.

Choose the field type that matches the content you need. See [Field types](/features/fields-guide) for the complete list and guidance.

## Populate and publish

Create items in a collection and fill in their field values. Items have a slug, an order, and a status of `draft` or `live`. Use AI to help populate a collection with structured content, then review the results before publishing.

See [Manage items](/features/items-guide) for item status, slugs, ordering, and publishing.

A project groups the collections used for a site or a related area of content. Each collection belongs to a project, which keeps content models organized as your workspace grows.

## Project details

A project can include:

- A **title** and URL-friendly **slug**.
- An optional **description** and **cover image**.
- An optional **folder** for grouping projects.
- An **archived** state for projects you no longer need in active work.

Projects are associated with the user who owns them. Updating a project refreshes its `updatedAt` timestamp.

## Organize projects with folders

Use project folders to group related projects, such as by site, team, or environment. Folders have a name and slug and are associated with their owner.

# Betacms documentation

Documentation for Betacms, a CMS for creating, managing, and publishing dynamic content.

## Run locally

Install the [Mintlify CLI](https://www.npmjs.com/package/mint), then start the docs site from this directory:

```bash
npm install -g mint
mint dev
```

The local preview runs at `http://localhost:3000`.
